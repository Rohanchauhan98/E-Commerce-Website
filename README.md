
# E-Commerce Website

A responsive e-commerce web application built using React, featuring user authentication and online payment integration.

## Features

- Responsive user interface for browsing products.
- User authentication using Google Firebase.
- Online payment integration using Razorpay.
- State management using Redux Toolkit.
- UI components and styling using Material UI.
- Client-side navigation using React Router.

## Tech Stack

- **Frontend:** React.js, JavaScript, HTML, CSS
- **State Management:** Redux Toolkit, React Redux
- **Authentication:** Firebase
- **Payments:** Razorpay
- **UI Library:** Material UI
- **Tools:** Git, GitHub, Node.js, npm

## Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Rohanchauhan98/E-Commerce-Website.git
   ```

2. Navigate to the project directory:

   ```bash
   cd E-Commerce-Website
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open your browser at `http://localhost:3000`.

## Project Purpose

This project demonstrates frontend development, state management, user authentication, and payment gateway integration in an e-commerce application.
